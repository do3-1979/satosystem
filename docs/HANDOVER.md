## 1. 自動売買BOTを断念した経緯

約1年半、暗号資産・株式・ETFの自動売買BOTを自作して検証しましたが、
**2026年8月に「個人の自作BOTに投資妙味はない」と結論づけて開発を終了しました。**

検証した戦略と結果は以下のとおりです（t値は統計的有意性の指標で、t>2を有意とみなしました。
計算式は Sharpe ÷ √((1+SR²/2)÷年数) です）。

| 戦略 | 統計的有意性 | 結末 |
|---|---|---|
| ドンチャンブレイクアウト（初代） | — | 棄却。3.5ヶ月ゼロ取引。しかもバックテストの約定ロジック自体が誤っていた |
| 日本株スクリーニング（大型76銘柄） | t=0.20 | 棄却。ベンチマークに勝てず |
| 古典的テクニカル（ローソク足パターン・各種オシレータ） | RSIのみ有意 | 棄却。BOT化すると買い持ちに負けた |
| キャリー戦略 | — | 棄却 |
| 暗号資産CTA（金トークン含む7銘柄） | t=1.75 | 有意水準に未達。加えて運用先だったBitgetが2026年8月3日に日本撤退を発表し消滅 |
| 米国ETF CTA（19銘柄） | t=2.50（有意） | レバレッジが前提。現物のみだと年0.7%しか出ない |
| 東証ETF CTA（7銘柄） | t=2.95（有意） | 統計的には有意。しかしNISAの非課税に勝てなかった |

### 最も重要だった発見

**エッジの正体はシグナルの巧妙さではなく、低相関資産の分散でした。**
ユニバースの平均ペア相関が、そのまま戦略成績の順序と一致しました（例外なし・単調）。

| 資産群 | 平均相関 | 結果 |
|---|---|---|
| 米国ETF 多資産24銘柄 | 0.209 | t=2.07 有意 |
| 東証ETF 7銘柄 | 0.330 | t=2.95 有意 |
| 暗号資産7銘柄（金含む） | 0.357 | t=1.75 未確認 |
| 日本株 大型76銘柄 | 0.420 | 不成立 |
| 暗号資産（金を除く） | 0.672 | ほぼコイン投げ |

### 断念した4つの構造的理由

1. **税制の非対称性** — NISAは非課税、BOTの利益は毎年20.315%課税されます。
   しかも証券会社の発注API（三菱UFJ eスマート証券のkabuステーションAPI）は仕様上
   **NISA口座を指定できません**。制度的に、自動売買は非課税の恩恵を受けられない設計でした
2. **レバレッジが使えない** — 機関投資家のCTAは先物で2〜5倍のグロスを持ちます。
   個人の現物口座は1.0倍が上限です。米国ETF版は年8.86%だったものが、現物制約を入れると年0.7%に落ちました
3. **使える商品が足りない** — 東証には流動性のある長期米国債ETFも通貨ETFもありません。
   危機時に上がる資産を持てず、コロナ暴落では-22.4%を食らいました
4. **資金規模** — 30万円だと売買単位の量子化が効いてしまいます

### デイトレード型BOTも検討したが見送りました

- 学術研究の結果が一貫して厳しい。ブラジルの調査では**300日以上続けた1,551人の97%が損失**、
  最低賃金を超えたのは1%未満。台湾の全取引記録の調査では**継続的に利益を出せたのは1%未満**でした
- 往復コストの壁。日本株を1日5往復すると年188%のコストになります
- 裁量トレーダーが語る「条件」は、多くの場合エッジの正体ではなく後付けの合理化です
- 儲かっている少数はHFT業者で、自宅回線とはレイテンシが5〜6桁違います

### S&P500を選んだ経緯と、理解している注意点

15.8年の実績（円建て・30万円を投じた場合）で比較しました。

| 選択肢 | 年率 | 15.8年後 |
|---|---|---|
| eMAXIS Slim S&P500（NISA・非課税） | 21.0% | 508万円 |
| eMAXIS Slim オルカン（NISA・非課税） | 16.6% | 294万円 |
| 東証ETF-CTA BOT（税引後） | 10.2% | 127万円 |

ただし、この差が**期間依存であること**は理解しています。

- 2003〜2010年（米国の失われた10年）は S&P500 年+1.2% に対し、全世界分散が年+3.7%で**逆転**
- 通期2003〜2026年（23年）では S&P500 年13.1% 対 全世界 年11.9%。差は年1.2ポイント
- 5年ローリングでS&P500の勝率は82.3%。裏を返せば**17.7%の期間は負けており、最大で5年累計-20.6%の劣後**
- **円建てでは2008年に-63%のドローダウン**がありました（危機時は円高が重なるため、ドル建てより深く沈みます）

## 4. 相談したいこと

### メインテーマ：企業型確定拠出年金（401k）の運用プラン

**前提条件**

- 運営管理機関: 野村證券
- 現在の運用商品: 外国株式（利益が出ている）
- 退職まで: 10〜20年
- **退職一時金（退職金）制度が別途あります**
- マッチング拠出: 「上限まで利用中」と認識していますが、後述の2026年4月の改正を反映できていない可能性があります

**2026年の制度改正（把握している内容）**

| 施行 | 内容 |
|---|---|
| 2026年1月 | 退職所得控除の「5年ルール」が「10年ルール」に厳格化 |
| 2026年4月 | マッチング拠出の「従業員掛金は会社掛金を超えてはならない」という制限が撤廃 |
| 2026年12月 | 拠出限度額が月5.5万円から6.2万円へ（2027年1月拠出分から） |

**すでに受けたアドバイス**

1. **最優先はマッチング拠出の増額余地の確認。**
   2026年4月の改正で上限の考え方が変わったため、会社掛金が月27,500円未満なら増額余地があります。
   たとえば会社掛金が月20,000円の場合、自分の拠出上限は20,000円から35,000円に広がります。

   掛金は全額所得控除なので、運用成績と無関係に確定でリターンが出ます。
   月15,000円の増額を15年続けると、節税81万円＋資産408万円で**合計約489万円の効果**でした
   （税率30%・運用年率5%と仮定した場合）。

2. **運用配分は外国株式100%の継続でよい。**
   確定拠出年金はスイッチング（預け替え）が無料・非課税なので、出口が近づいてから配分を変えれば十分です。
   守りに入る目安は「受取5年前から段階的に」。5年前に株式80%、3年前に60%、1年前に30%といった落とし方です。
   理由は、受取直前の暴落は回復を待てないためです。

3. **出口設計。** 退職一時金があるため受取順序が効きます。
   - 確定拠出年金が先、退職金が後 → 10年空ける必要（2026年1月に5年から延長された）
   - 退職金が先、確定拠出年金が後 → 19年空ける必要（従来どおり）
   - 確定拠出年金の受給開始は75歳まで繰り下げでき、その間も非課税で運用が続きます
   - 退職金額と確定拠出年金残高の大小によって有利な順序が変わるため、退職の10年前頃から具体的に検討する

**まだ整理できていない情報**（相談を深めるために自分で調べる必要があるもの）

- 現在の確定拠出年金の残高、会社掛金とマッチング拠出の月額
- 退職金の見込額（就業規則・退職金規程に記載されているはず）
- おおよその年収（税率の判定に必要）
- 確定拠出年金の商品ラインナップ、特に外国株式インデックスの信託報酬
  （確定拠出年金は商品によって0.1%〜0.9%と幅があると聞きました）
