## 改善の根拠となる現状診断

- **PnLの57%が金2銘柄（PAXG+XAUT=$656/$1156）**。ETHはマイナス。crypto単独トレンドは全サイクルでエッジ薄（Sharpe~0.2、research確定済）→ 最大のレバーは**低相関資産の追加**。
- **コストドラッグ年4.4%**（対リターン17.5%の1/4）。内訳: funding $129 > fee $69 > slippage $63。3xストレスでSharpe 0.37に劣化 → **コスト削減は第二のレバー**。
- 負け年は2023のみ（whipsaw、-15.9%）。TSMOMの構造的弱点として認識済み。
- 資本$1,000のため signal_deviation 累計$64 ≒ fee総額に匹敵（丸め・執行摩擦）。

## P1: 今すぐ検証可能（既存データ・コード変更小）

### 1. ユニバース拡大①: キャッシュ済み5銘柄の追加 — `棄却(2026-07-03検証)`
ADA/AVAX/DOGE/LINK/LTC を追加した12銘柄でフル検証（out/validation_univ12.json, config/exp_univ12.ini）。
- **結果: Sharpe 1.00→0.59 / 年17.5%→10.3% / DD同等28.1% / 3xコストストレスでマイナス転落(-3.5%)**。
- 5アルト自体は全部プラス（+$6〜35）だが、金+BTCのリスクバジェットを半減させる希薄化が支配的。
  集中度は改善(top_asset_share 0.28→0.21)するがPnLは半減。crypto内追加は「保険」にならない
  （高相関で同時に死ぬ）— 分散価値があるのは**低相関資産(非crypto)のみ**。→ #4(SPX等)が本命。

### 2. maker執行への切替（fee 0.055% → 0.02%） — `採用候補(執行レイヤー設計が前提)`
fee_rate=0.02%での机上検証（out/validation_maker.json, config/exp_maker.ini）。
- **結果: Sharpe 1.00→1.03 / 年+17.5%→+18.0% / DD 28.1%→27.4%。真価はコスト耐性:
  3x +6.1%→+9.1%、5x 死亡(halt)→生存(+0.7%)**。
- ただしfeeを下げるだけでは楽観化。**次アクション: maker fillシミュレーション実装**
  （指値=シグナルバー終値、次バーhigh/lowで約定判定、未約定はtaker fallback）→ fill率込みで再検証。
  ペーパーは保守的にtaker継続（実測fill率が取れたら切替）。
- 注意: carry tilt（シグナル側のfunding傾斜）は検証済み棄却。これは執行レイヤーの話で別物。

### 3. 相関考慮配分（金クラスタ統合） — `棄却(2026-07-03検証)`
PAXG+XAUTのraw配分を1/2（金=1資産扱い）で検証（out/validation_goldcluster.json）。
- **結果: Sharpe 1.00→0.82 / 年17.5%→14.0% / DD 28.1%→25.6%(微改善) / 3x +6.1%→+4.3%**。
- 理論上正しい二重計上是正だが、牽引資産の金を削り年3.5pt喪失。DD改善は小さく見合わない。
- **含意（明記しておく）: 現行configは金に実質2倍のリスク配分をする暗黙のベット**。
  過去4.7年はこれが正解だったが、金トレンド終了時は逆風になる。ペーパーOOSで監視する。
